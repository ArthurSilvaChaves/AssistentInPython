# Assistent in Python 💻

## Description 📰
assistent in python, simple in the terminal, two languages(English and Portuguese) and a visual version(GUI)

## Features ⚙
### Automation for open navegator 
- firefox,chrome,edge are supported
### Get cotation 
- BRL, USD, JPY and BTC
### Convertion tool 
- temperature, Distance and Weight to convertion
### Weather in real time 
- Temperature, Wind Speed, Rain e Precipitation in your local ip
### Hour in details
- day, mounth, year and week day
### See notices about notices 
- this feature may to improve
### Choose something random 
- musics, movies, series, muscular groups and random youtube channel choosed in a random list
### a simple game to spend time
- its named falling blocks, made in pygame lib
### head or tails
- coin feature
### audio recongizer to voice command 
- some additional features and commands

## Technologies 🤖
- Python 3.12.3 with venv virtual environment
- Libs in python like pyautogui to automations, requests to use api's, speech_recognition and pyttsx3 to voice command and speech 

## How to execute ⏩
1. clone the repository
2. execute the archive "python main.py"

## Manual to Visual Version of this app📺
### To use conversion tools (currenry and other values like temperature, distance and weight)
- in the first input, enter the __value__ that you want to convert
- in the the second input, enter the __measure or currency__ that you want to convert
- finally, in the third input, enter the __measure or currency__ you want to convert to

### To use "🎙️"(microphone feature)
- for while this feature is not operative, but soon will 
- press the button and say something
- *do not wait*, otherwise the recognition period will pass

### To use the weather feature
1. press "weather" button
2. write temperate, wind speed or rain in the main entry
3. there is it !
